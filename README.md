# Orpheus House - CSS Learning Project - Website

A static website for Orpheus House, an Airbnb accommodation.

Live website: https://www.orpheushouse.eu/

## About the Project

August 2026 was a month for learning something new: **CSS**.

I started learning CSS with an idea and my wife's desire to have a static website for her Airbnb. After some time learning and experimenting, I started building the website based on a Canva PDF design she had made.

The goal was to create a simple, responsive website to present to the visitor the accommodation and provide useful information about the property.
